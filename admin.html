First time here?

Go to Settings and paste your GitHub token so this page can save cards to your site.

1. Choose photos

Pick a binder page photo to cut it into separate cards, or pick photos of single cards. You can take a new photo or choose from your gallery.

2. Line up the grid

Make the red boxes sit on the cards. Pick the layout, then nudge the edges until each box covers one card.

3. Name your cards

Check each name (fix any the scanner got wrong), and remove empty pockets. Adding a back photo is optional — you can do it later from Edit cards.

Edit cards

Rename cards, add or replace front/back photos, or delete cards. Changes are highlighted until you save.

Connect to GitHub

Your cards and photos are stored in your GitHub repository. This page needs a token to save to it. The token is only kept on this device — do this once on your phone and once on your PC.

How to get a token

  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it “Pokemon cards site”, pick an expiration (up to 1 year).
  3. Under Repository access choose Only select repositories → your cards repository.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Generate, copy the token and paste it above.
